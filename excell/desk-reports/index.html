Debbie's Three Reports

Three quick reports so Jimmy can set up the money follow-up for Dr. McCray. About 45 minutes total. Please finish by Friday.

The one rule: no patient information, ever.

No names, birthdays, phone numbers, addresses, claim numbers or accident dates. Use the row numbers instead. If you're unsure whether something counts, leave it out.

Report 1 · about 30 minutes

The personal-injury (PI) list

  1. Open your PI spreadsheet (the one you already keep).
  2. Open the blank sheet: PI list for Jimmy (no patient names). It has 52 numbered rows, one per open case.
  3. For each case, fill in one row: the attorney or firm, how old the case is, the balance owed, whether a signed lien is on file, when you last heard from the attorney, and the status. Each column shows the choices.
  4. In your own spreadsheet, write the row number next to each case so you know which is which. That key stays with you.

Not sure about a box? Leave it blank. Blanks tell us what to follow up on.

Report 2 · about 5 minutes

What we sell (Square)

  1. Log in to the Square Dashboard on the computer.
  2. Go to Reports, then Item sales.
  3. Set the dates to the last 90 days.
  4. Click Export and choose CSV.
  5. Drop the file into the shared folder: Excell × Jimmy · Shared Files.

This report lists products and totals only, with no customer names. If you see a customer column, delete it before you upload.

Report 3 · about 10 minutes

Weekly session counts

  1. Open the blank sheet: Weekly session counts (totals only).
  2. For each of the last 8 weeks, write how many decompression sessions and how many hyperbaric sessions there were. Use the ChiroTouch schedule or your end-of-day sheet.

Just numbers, like "4" and "2". No names.

When you're done, text Dr. McCray "reports done." That's it. Thank you, Debbie!
