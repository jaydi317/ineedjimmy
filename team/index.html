WHAT THE COUNCIL NEEDS

Read first. Write only when approved.

Access is requested in two separate lanes so “understand the system” never silently becomes permission to change it.

👀

Needed to understand

Read-only views of Close, Stripe reporting, active offers and aliases, automation history, Sophia’s tracker, current SOPs, support categories, and one anonymized customer journey.

  • No customer messages
  • No deletions
  • No workflow changes
🔑

Needed to implement later

One scoped service account tied to one approved ticket, a test record, a named owner, a rollback plan, and a proof check.

  • Least privilege
  • Time-bounded access
  • Every change logged
Never put these here: passwords, full card numbers, raw customer health information, private credentials, or unrestricted admin access.
